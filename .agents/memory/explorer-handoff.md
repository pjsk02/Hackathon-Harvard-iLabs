name: Explorer handoff
description: Why the final evidence step opens the public explorer separately rather than embedding it.
---

Keep the evidence summary in Envoi and open the transaction explorer in a new tab rather than replacing the demonstration or embedding the entire explorer.

**Why:** The requested final demo moment is independent inspection of the actual public transaction. Keeping Envoi open preserves the presenter’s place, while avoiding reliance on a third-party explorer allowing iframe embedding.

**How to apply:** Preserve this separation when extending the evidence experience. A future request for an embedded explorer needs an explicit compatibility check rather than assuming the external site permits it.

The user specifically requested a prominent button to the exact real Monad transaction page, not an Envoi recreation of the explorer. Link the verified violation transaction, never the permission stamp as a substitute. Clean results have no transaction button.
